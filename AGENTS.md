# Agents: start here

echo is built and iterated by following one skill: `.claude/skills/humanoid-from-spec/SKILL.md`. Read it first, then
`LESSONS.md`, and work in the rounds it describes: one change, the checks, before/after pictures beside the
reference, the user's review. Publish only with the user's go-ahead.

The skill's `references/` folder holds the details:
- `reference-images.md`: getting reference images from the web and turning them into shapes;
- `spec-patterns.md`, `joint-covers.md`, `checks.md`: the spec, the joints and the checks;
- `fusion-mcp.md`: driving Fusion 360;
- `motion-and-publishing.md`, `sources.md`: motion, publishing, and every source with its licence.
